# Mesa — Hito 1 (Base): plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dejar funcionando la base de la plataforma: proyecto Next.js con la marca FByte, login, superadmin que da de alta restaurantes, invitaciones por email, panel con roles y seguridad RLS que aísla a cada restaurante.

**Architecture:** Una sola app Next.js 16 (App Router, `src/`) sobre Supabase. La seguridad vive en Postgres: RLS + funciones `SECURITY DEFINER` para las operaciones sensibles (crear restaurante, invitar, aceptar invitación). La app solo usa la clave de servicio en el servidor y solo para crear cuentas al aceptar invitaciones y para scripts. Las pruebas de BD corren contra un PostgreSQL 16 local con un "shim" que imita el esquema `auth` de Supabase.

**Tech Stack:** Next.js 16.4 · React 19 · TypeScript · Tailwind CSS 4 · Supabase (`@supabase/ssr` 0.12, `@supabase/supabase-js` 2.119) · Zod 4 · Resend 6 + React Email 1 · Vitest 4 · Playwright 1.63 · pnpm 10 · PostgreSQL 16 (pruebas).

**Spec:** `docs/superpowers/specs/2026-11-24-plataforma-restaurantes-design.md`

## Global Constraints

- Mercado España. Todo texto visible en castellano de España, con tuteo y la voz FByte: frases cortas, humanas, sin jerga ("Algo ha fallado. Vuelve a intentarlo en un momento.", nunca "Error 500").
- Nombre del producto **provisional** "Mesa": solo se escribe en `src/config/brand.ts`; el resto del código lo importa de ahí.
- Colores FByte: `ink #0A1330`, `navy #17317F`, `navy-dark #0F2260`, `orange #FF7A1A`, `orange-dark #E8650A`, `peach #FFC48A`, `peach-soft #FFE9D6`, `paper #F8F5EF`, `muted #3A4157`. **Nunca texto blanco sobre naranja**; botón principal = fondo `orange`, texto `ink`. Tipografía Archivo con eje `wdth`.
- Roles en BD: `admin` (Administrador), `manager` (Encargado), `staff` (Sala/Recepción). La BD es la fuente de verdad de los permisos.
- Toda tabla de negocio lleva `restaurant_id` y RLS activado. Ninguna tabla se expone a `anon` salvo `reserved_slugs`.
- Funciones `SECURITY DEFINER` siempre con `set search_path = ''` y nombres totalmente cualificados.
- La clave secreta de Supabase (`SUPABASE_SECRET_KEY`) nunca llega al navegador (`import 'server-only'`).
- Zona horaria por defecto `Europe/Madrid`; permitida también `Atlantic/Canary`.
- Slugs: `^[a-z0-9]+(-[a-z0-9]+)*$`, 3–60 caracteres, no reservados.
- Invitaciones: token aleatorio de 32 bytes (hex), en BD solo su hash SHA-256, caducan a los 7 días.
- Playwright: usar `@playwright/test@1.63.0` (coincide con el Chromium preinstalado) y ejecutar siempre con `--trace off`.
- Commits pequeños, uno por paso de "Commit". Mensajes en castellano.

- [ ] **Step 7: Implementar `src/lib/slug.ts`**

```ts
export const SLUG_PATTERN = /^[a-z0-9]+(-[a-z0-9]+)*$/;

/** Debe coincidir exactamente con la tabla public.reserved_slugs (lo comprueba tests/db/base.test.ts). */
export const RESERVED_SLUGS = [
  'admin',
  'panel',
  'login',
  'logout',
  'api',
  'auth',
  'invitacion',
  'recuperar',
  'nueva-contrasena',
  'legal',
  'privacidad',
  'cookies',
  'aviso-legal',
  'ayuda',
  'soporte',
  'static',
  'public',
  'assets',
  'brand',
  'www',
  'mesa',
  'fbyte',
] as const;

export function slugify(input: string): string {
  return input
    .normalize('NFD')
    .replace(/[̀-ͯ]/g, '')
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-+|-+$/g, '')
    .slice(0, 60)
    .replace(/-+$/g, '');
}

export function isReservedSlug(slug: string): boolean {
  return (RESERVED_SLUGS as readonly string[]).includes(slug);
}

export function isValidSlug(slug: string): boolean {
  return slug.length >= 3 && slug.length <= 60 && SLUG_PATTERN.test(slug);
}
```

```ts
import pg from 'pg';
import { expect } from 'vitest';

export const pool = new pg.Pool({
  connectionString: process.env.PG_TEST_URL ?? 'postgresql://postgres@127.0.0.1:54329/mesa_test',
  max: 4,
});

export type TestUser = { id: string; email: string };
export type Role = 'admin' | 'manager' | 'staff';

/** Ejecuta fn dentro de una transacción que siempre se deshace. */
export async function tx<T>(fn: (c: pg.PoolClient) => Promise<T>): Promise<T> {
  const c = await pool.connect();
  await c.query('begin');
  try {
    return await fn(c);
  } finally {
    await c.query('rollback');
    c.release();
  }
}

/** Cambia la identidad de la conexión: un usuario autenticado o anon (null). */
export async function as(c: pg.PoolClient, user: TestUser | null): Promise<void> {
  await c.query('reset role');
  await c.query("select set_config('request.jwt.claims', $1, true)", [
    user ? JSON.stringify({ sub: user.id, email: user.email, role: 'authenticated' }) : '',
  ]);
  await c.query(user ? 'set local role authenticated' : 'set local role anon');
}

/** Vuelve a superusuario (para preparar datos). */
export async function asSuperuser(c: pg.PoolClient): Promise<void> {
  await c.query('reset role');
  await c.query("select set_config('request.jwt.claims', '', true)");
}

export async function createUser(
  c: pg.PoolClient,
  email: string,
  opts: { fullName?: string; platformAdmin?: boolean } = {},
): Promise<TestUser> {
  await asSuperuser(c);
  const { rows } = await c.query<{ id: string }>(
    'insert into auth.users (email, raw_user_meta_data) values ($1, $2) returning id',
    [email, { full_name: opts.fullName ?? email.split('@')[0] }],
  );
  if (opts.platformAdmin) {
    await c.query('update public.profiles set is_platform_admin = true where user_id = $1', [rows[0].id]);
  }
  return { id: rows[0].id, email };
}

export async function insertRestaurant(
  c: pg.PoolClient,
  r: { name: string; slug: string; status?: 'setup' | 'active' | 'disabled' },
): Promise<string> {
  await asSuperuser(c);
  const { rows } = await c.query<{ id: string }>(
    'insert into public.restaurants (name, slug, status) values ($1, $2, $3) returning id',
    [r.name, r.slug, r.status ?? 'active'],
  );
  return rows[0].id;
}

export async function addMember(c: pg.PoolClient, restaurantId: string, userId: string, role: Role): Promise<void> {
  await asSuperuser(c);
  await c.query('insert into public.restaurant_members (restaurant_id, user_id, role) values ($1, $2, $3)', [
    restaurantId,
    userId,
    role,
  ]);
}

/** Espera que la consulta falle con un mensaje que encaje con pattern, sin romper la transacción. */
export async function expectDbError(
  c: pg.PoolClient,
  sql: string,
  params: unknown[],
  pattern: RegExp,
): Promise<void> {
  await c.query('savepoint expect_err');
  let error: unknown;
  try {
    await c.query(sql, params);
  } catch (e) {
    error = e;
  }
  await c.query('rollback to savepoint expect_err');
  expect(error, `se esperaba un error ${pattern}`).toBeDefined();
  expect(String((error as Error).message)).toMatch(pattern);
}
```

```sql
/** Interna: crea (o reemplaza) la invitación pendiente y devuelve el token en claro. */
create or replace function public._new_invitation(p_restaurant_id uuid, p_email text, p_role public.member_role)
returns text language plpgsql security definer set search_path = '' as $$
declare
  v_email text := lower(trim(p_email));
  v_token text := encode(extensions.gen_random_bytes(32), 'hex');
begin
  if v_email !~ '^[^@\s]+@[^@\s]+\.[^@\s]+$' then
    raise exception 'INVALID_EMAIL' using errcode = '22023';
  end if;
  delete from public.invitations
   where restaurant_id = p_restaurant_id and email = v_email and accepted_at is null;
  insert into public.invitations (restaurant_id, email, role, token_hash, invited_by)
  values (p_restaurant_id, v_email, p_role, encode(extensions.digest(v_token, 'sha256'), 'hex'), auth.uid());
  return v_token;
end $$;

create or replace function public.create_restaurant(p_name text, p_slug text, p_admin_email text)
returns table (restaurant_id uuid, invitation_token text)
language plpgsql security definer set search_path = '' as $$
declare
  v_id uuid;
  v_token text;
begin
  if not public.is_platform_admin() then
    raise exception 'FORBIDDEN' using errcode = '42501';
  end if;
  insert into public.restaurants (name, slug) values (trim(p_name), lower(trim(p_slug))) returning id into v_id;
  v_token := public._new_invitation(v_id, p_admin_email, 'admin');
  insert into public.admin_audit_log (actor_id, action, restaurant_id, details)
  values (auth.uid(), 'restaurant.create', v_id, jsonb_build_object('admin_email', lower(trim(p_admin_email))));
  return query select v_id, v_token;
end $$;

create or replace function public.create_invitation(p_restaurant_id uuid, p_email text, p_role public.member_role)
returns text language plpgsql security definer set search_path = '' as $$
declare
  v_email text := lower(trim(p_email));
begin
  if auth.uid() is null or not (public.has_role(p_restaurant_id, '{admin}') or public.is_platform_admin()) then
    raise exception 'FORBIDDEN' using errcode = '42501';
  end if;
  if exists (
    select 1 from public.restaurant_members m join auth.users u on u.id = m.user_id
    where m.restaurant_id = p_restaurant_id and lower(u.email) = v_email
  ) then
    raise exception 'ALREADY_MEMBER' using errcode = 'P0001';
  end if;
  return public._new_invitation(p_restaurant_id, v_email, p_role);
end $$;

create or replace function public.get_invitation(p_token text)
returns table (restaurant_id uuid, restaurant_name text, email text, role public.member_role, has_account boolean)
language sql stable security definer set search_path = '' as $$
  select i.restaurant_id, r.name, i.email, i.role,
         exists (select 1 from auth.users u where lower(u.email) = i.email)
  from public.invitations i
  join public.restaurants r on r.id = i.restaurant_id
  where i.token_hash = encode(extensions.digest(p_token, 'sha256'), 'hex')
    and i.accepted_at is null
    and i.expires_at > now()
    and r.status <> 'disabled'
$$;

create or replace function public.accept_invitation(p_token text)
returns uuid language plpgsql security definer set search_path = '' as $$
declare
  v_inv public.invitations%rowtype;
  v_email text;
begin
  if auth.uid() is null then
    raise exception 'NOT_AUTHENTICATED' using errcode = '42501';
  end if;
  select i.* into v_inv
  from public.invitations i
  join public.restaurants r on r.id = i.restaurant_id
  where i.token_hash = encode(extensions.digest(p_token, 'sha256'), 'hex')
    and i.accepted_at is null
    and i.expires_at > now()
    and r.status <> 'disabled'
  for update of i;
  if not found then
    raise exception 'INVALID_INVITATION' using errcode = 'P0001';
  end if;
  select lower(u.email) into v_email from auth.users u where u.id = auth.uid();
  if v_email is distinct from v_inv.email then
    raise exception 'EMAIL_MISMATCH' using errcode = 'P0001';
  end if;
  insert into public.restaurant_members (restaurant_id, user_id, role)
  values (v_inv.restaurant_id, auth.uid(), v_inv.role)
  on conflict (restaurant_id, user_id) do update set role = excluded.role;
  update public.invitations set accepted_at = now(), accepted_by = auth.uid() where id = v_inv.id;
  return v_inv.restaurant_id;
end $$;

create or replace function public.set_restaurant_status(p_restaurant_id uuid, p_status public.restaurant_status)
returns void language plpgsql security definer set search_path = '' as $$
begin
  if not public.is_platform_admin() then
    raise exception 'FORBIDDEN' using errcode = '42501';
  end if;
  update public.restaurants set status = p_status where id = p_restaurant_id;
  insert into public.admin_audit_log (actor_id, action, restaurant_id, details)
  values (auth.uid(), 'restaurant.status', p_restaurant_id, jsonb_build_object('status', p_status));
end $$;

create or replace function public.log_admin_view(p_restaurant_id uuid)
returns void language plpgsql security definer set search_path = '' as $$
begin
  if not public.is_platform_admin() then
    raise exception 'FORBIDDEN' using errcode = '42501';
  end if;
  insert into public.admin_audit_log (actor_id, action, restaurant_id) values (auth.uid(), 'support.view', p_restaurant_id);
end $$;

create or replace function public.restaurant_team(p_restaurant_id uuid)
returns table (user_id uuid, full_name text, email text, role public.member_role, joined_at timestamptz)
language plpgsql stable security definer set search_path = '' as $$
begin
  if not (public.is_member(p_restaurant_id) or public.is_platform_admin()) then
    raise exception 'FORBIDDEN' using errcode = '42501';
  end if;
  return query
    select m.user_id, p.full_name, u.email::text, m.role, m.created_at
    from public.restaurant_members m
    join auth.users u on u.id = m.user_id
    left join public.profiles p on p.user_id = m.user_id
    where m.restaurant_id = p_restaurant_id
    order by m.created_at;
end $$;
```

```ts
export function safeNext(next: string | null | undefined, fallback = '/panel'): string {
  if (!next || !next.startsWith('/') || next.startsWith('//') || next.startsWith('/\\')) return fallback;
  return next;
```

```ts
import 'server-only';
import { z } from 'zod';

const schema = z.object({
  NEXT_PUBLIC_SUPABASE_URL: z.url(),
  NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY: z.string().min(1),
  SUPABASE_SECRET_KEY: z.string().min(1),
  NEXT_PUBLIC_SITE_URL: z.url(),
  RESEND_API_KEY: z.string().optional(),
  EMAIL_FROM: z.string().min(3).default('Mesa <onboarding@resend.dev>'),
});

export type ServerEnv = z.infer<typeof schema>;

export function serverEnv(): ServerEnv {
  const parsed = schema.safeParse({
    NEXT_PUBLIC_SUPABASE_URL: process.env.NEXT_PUBLIC_SUPABASE_URL || undefined,
    NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY: process.env.NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY || undefined,
    SUPABASE_SECRET_KEY: process.env.SUPABASE_SECRET_KEY || undefined,
    NEXT_PUBLIC_SITE_URL: process.env.NEXT_PUBLIC_SITE_URL || undefined,
    RESEND_API_KEY: process.env.RESEND_API_KEY || undefined,
    EMAIL_FROM: process.env.EMAIL_FROM || undefined,
  });
  if (!parsed.success) {
    const keys = parsed.error.issues.map((i) => i.path.join('.')).join(', ');
    throw new Error(`Faltan o son incorrectas estas variables de entorno: ${keys}. Revisa .env.example.`);
  }
  return parsed.data;
}

export function siteUrl(): string {
  return serverEnv().NEXT_PUBLIC_SITE_URL.replace(/\/+$/, '');
```

```ts
import { createServerClient } from '@supabase/ssr';
import { NextResponse, type NextRequest } from 'next/server';

/** Refresca el token de Supabase en cada petición y lo propaga a la respuesta. */
export async function updateSession(request: NextRequest) {
  let response = NextResponse.next({ request });

  const supabase = createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY!,
    {
      cookies: {
        getAll() {
          return request.cookies.getAll();
        },
        setAll(cookiesToSet, headers) {
          cookiesToSet.forEach(({ name, value }) => request.cookies.set(name, value));
          response = NextResponse.next({ request });
          cookiesToSet.forEach(({ name, value, options }) => response.cookies.set(name, value, options));
          // Cabeceras anti-caché para que una CDN no comparta la sesión
          Object.entries(headers ?? {}).forEach(([key, value]) => response.headers.set(key, String(value)));
        },
      },
    },
  );

  await supabase.auth.getClaims();
  return response;
}
```

```ts
import 'server-only';
import { notFound, redirect } from 'next/navigation';
import { cache } from 'react';
import { can, type Permission, type Role } from '@/lib/permissions';
import { createClient } from '@/lib/supabase/server';
import { uuidSchema } from '@/lib/validation/schemas';

export type SessionUser = { id: string; email: string };
export type RestaurantStatus = 'setup' | 'active' | 'disabled';
export type MyRestaurant = { id: string; name: string; slug: string; status: RestaurantStatus; role: Role };
export type PanelContext = {
  user: SessionUser;
  restaurant: { id: string; name: string; slug: string; status: RestaurantStatus };
  role: Role;
  readOnly: boolean;
};

export const getUser = cache(async (): Promise<SessionUser | null> => {
  const supabase = await createClient();
  const { data } = await supabase.auth.getUser();
  if (!data.user?.email) return null;
  return { id: data.user.id, email: data.user.email };
});

export async function requireUser(next?: string): Promise<SessionUser> {
  const user = await getUser();
  if (!user) redirect(next ? `/login?next=${encodeURIComponent(next)}` : '/login');
  return user;
}

export const isPlatformAdmin = cache(async (): Promise<boolean> => {
  const supabase = await createClient();
  const { data } = await supabase.rpc('is_platform_admin');
  return data === true;
});

export async function requirePlatformAdmin(): Promise<SessionUser> {
  const user = await requireUser('/admin');
  if (!(await isPlatformAdmin())) notFound();
  return user;
}

export const getMyRestaurants = cache(async (): Promise<MyRestaurant[]> => {
  const supabase = await createClient();
  const { data, error } = await supabase.rpc('my_restaurants');
  if (error) throw new Error(error.message);
  return (data ?? []) as MyRestaurant[];
});

export const getPanelContext = cache(async (restaurantId: string): Promise<PanelContext> => {
  if (!uuidSchema.safeParse(restaurantId).success) notFound();
  const user = await requireUser(`/panel/${restaurantId}`);
  const mine = (await getMyRestaurants()).find((r) => r.id === restaurantId);
  if (mine) {
    const { role, ...restaurant } = mine;
    return { user, restaurant, role, readOnly: false };
  }
  if (await isPlatformAdmin()) {
    const supabase = await createClient();
    const { data } = await supabase.from('restaurants').select('id, name, slug, status').eq('id', restaurantId).maybeSingle();
    if (!data) notFound();
    // FByte entra en modo soporte: ve como un administrador, pero no puede tocar nada.
    return { user, restaurant: data as PanelContext['restaurant'], role: 'admin', readOnly: true };
  }
  notFound();
});

/** Para server actions: lanza FORBIDDEN si no se puede actuar. */
export async function requirePermission(restaurantId: string, permission: Permission): Promise<PanelContext> {
  const ctx = await getPanelContext(restaurantId);
  if (ctx.readOnly || ctx.restaurant.status === 'disabled' || !can(ctx.role, permission)) {
    throw new Error('FORBIDDEN');
  }
  return ctx;
}
```

```ts
import type { FormState } from '@/lib/forms';
import { safeNext } from '@/lib/safe-next';
import { createClient } from '@/lib/supabase/server';
import { loginSchema } from '@/lib/validation/schemas';

export async function signIn(_prev: FormState, formData: FormData): Promise<FormState> {
  const parsed = loginSchema.safeParse({ email: formData.get('email'), password: formData.get('password') });
  if (!parsed.success) return { error: 'Revisa el email y la contraseña.' };
  const supabase = await createClient();
  const { error } = await supabase.auth.signInWithPassword(parsed.data);

  redirect(safeNext(String(formData.get('next') ?? '')));
}
```

Create `src/app/auth/confirm/route.ts`:

```ts
import type { EmailOtpType } from '@supabase/supabase-js';
import { NextResponse, type NextRequest } from 'next/server';
import { safeNext } from '@/lib/safe-next';
import { createClient } from '@/lib/supabase/server';

export async function GET(request: NextRequest) {
  const url = new URL(request.url);
  const code = url.searchParams.get('code');
  const tokenHash = url.searchParams.get('token_hash');
  const type = url.searchParams.get('type') as EmailOtpType | null;
  const next = safeNext(url.searchParams.get('next'));

  const supabase = await createClient();
  let ok = false;
  if (code) {
    ok = !(await supabase.auth.exchangeCodeForSession(code)).error;
  } else if (tokenHash && type) {
    ok = !(await supabase.auth.verifyOtp({ type, token_hash: tokenHash })).error;
  }
  return NextResponse.redirect(new URL(ok ? next : '/recuperar?error=enlace', request.url));
}
```

Create `src/lib/email/send.ts`:

```ts
import 'server-only';
import { Resend } from 'resend';
import { serverEnv } from '@/lib/env';

export type SendResult = { ok: true; id?: string } | { ok: false; error: string };

export async function sendEmail(input: {
  to: string;
  subject: string;
  react: React.ReactElement;
  replyTo?: string;
}): Promise<SendResult> {
  const env = serverEnv();
  if (!env.RESEND_API_KEY) {
    // Modo desarrollo: sin clave no se envía nada.
    console.info(`[email:dev] a=${input.to} asunto="${input.subject}"`);
    return { ok: true };
  }
  try {
    const resend = new Resend(env.RESEND_API_KEY);
    const { data, error } = await resend.emails.send({
      from: env.EMAIL_FROM,
      to: input.to,
      subject: input.subject,
      react: input.react,
      replyTo: input.replyTo,
    });
    if (error) {
      console.error('[email] Resend rechazó el envío', { subject: input.subject, error: error.message });
      return { ok: false, error: error.message };
    }
    return { ok: true, id: data?.id };
  } catch (e) {
    console.error('[email] fallo de red al enviar', { subject: input.subject });
    return { ok: false, error: e instanceof Error ? e.message : 'unknown' };
  }
}
```

```ts
'use server';

import { revalidatePath } from 'next/cache';
import { getPanelContext, isPlatformAdmin } from '@/lib/auth/guards';
import { mapDbError } from '@/lib/db-errors';
import { sendInvitationEmail } from '@/lib/email/invitation';
import { fieldErrorsFrom, type FormState } from '@/lib/forms';
import { invitationUrl } from '@/lib/invitations';
import { can, ROLES, type Role } from '@/lib/permissions';
import { createClient } from '@/lib/supabase/server';
import { inviteMemberSchema, uuidSchema } from '@/lib/validation/schemas';

export type InviteState = FormState & { inviteUrl?: string; email?: string; emailSent?: boolean };

/** Puede gestionar el equipo: administrador del restaurante (no en modo soporte) o FByte. */
async function assertCanManageTeam(restaurantId: string): Promise<{ restaurantName: string }> {
  if (!uuidSchema.safeParse(restaurantId).success) throw new Error('FORBIDDEN');
  const ctx = await getPanelContext(restaurantId);
  const allowed = ctx.readOnly ? await isPlatformAdmin() : can(ctx.role, 'users.manage') && ctx.restaurant.status !== 'disabled';
  if (!allowed) throw new Error('FORBIDDEN');
  return { restaurantName: ctx.restaurant.name };
}

function revalidateTeam(restaurantId: string) {
  revalidatePath(`/panel/${restaurantId}/usuarios`);
  revalidatePath(`/admin/restaurantes/${restaurantId}`);
}

export async function inviteMember(_prev: InviteState, fd: FormData): Promise<InviteState> {
  const restaurantId = String(fd.get('restaurantId') ?? '');
  const parsed = inviteMemberSchema.safeParse({ email: fd.get('email'), role: fd.get('role') });
  if (!parsed.success) return { fieldErrors: fieldErrorsFrom(parsed.error) };
  try {
    const { restaurantName } = await assertCanManageTeam(restaurantId);
    const supabase = await createClient();
    const { data: token, error } = await supabase.rpc('create_invitation', {
      p_restaurant_id: restaurantId,
      p_email: parsed.data.email,
      p_role: parsed.data.role,
    });
    if (error || typeof token !== 'string') return { error: mapDbError(error?.message) };
    const url = invitationUrl(token);
    const sent = await sendInvitationEmail({ to: parsed.data.email, restaurantName, role: parsed.data.role, inviteUrl: url });
    revalidateTeam(restaurantId);
    return { success: 'Invitación creada.', inviteUrl: url, email: parsed.data.email, emailSent: sent.ok };
  } catch (e) {
    return { error: mapDbError(e instanceof Error ? e.message : undefined) };
  }
}

export async function changeMemberRole(_prev: FormState, fd: FormData): Promise<FormState> {
  const restaurantId = String(fd.get('restaurantId') ?? '');
  const userId = String(fd.get('userId') ?? '');
  const role = String(fd.get('role') ?? '') as Role;
  if (!ROLES.includes(role) || !uuidSchema.safeParse(userId).success) return { error: 'Elige un rol.' };
  try {
    await assertCanManageTeam(restaurantId);
    const supabase = await createClient();
    const { data, error } = await supabase
      .from('restaurant_members')
      .update({ role })
      .eq('restaurant_id', restaurantId)
      .eq('user_id', userId)
      .select('user_id');
    if (error) return { error: mapDbError(error.message) };
    if (!data?.length) return { error: mapDbError('FORBIDDEN') };
    revalidateTeam(restaurantId);
    return { success: 'Rol actualizado.' };
  } catch (e) {
    return { error: mapDbError(e instanceof Error ? e.message : undefined) };
  }
}

export async function removeMember(_prev: FormState, fd: FormData): Promise<FormState> {
  const restaurantId = String(fd.get('restaurantId') ?? '');
  const userId = String(fd.get('userId') ?? '');
  if (!uuidSchema.safeParse(userId).success) return { error: mapDbError(undefined) };
  try {
    await assertCanManageTeam(restaurantId);
    const supabase = await createClient();
    const { data, error } = await supabase
      .from('restaurant_members')
      .delete()
      .eq('restaurant_id', restaurantId)
      .eq('user_id', userId)
      .select('user_id');
    if (error) return { error: mapDbError(error.message) };
    if (!data?.length) return { error: mapDbError('FORBIDDEN') };
    revalidateTeam(restaurantId);
    return { success: 'Persona quitada del equipo.' };
  } catch (e) {
    return { error: mapDbError(e instanceof Error ? e.message : undefined) };
  }
}

export async function cancelInvitation(fd: FormData): Promise<void> {
  const restaurantId = String(fd.get('restaurantId') ?? '');
  const invitationId = String(fd.get('invitationId') ?? '');
  if (!uuidSchema.safeParse(invitationId).success) return;
  await assertCanManageTeam(restaurantId);
  const supabase = await createClient();
  await supabase.from('invitations').delete().eq('id', invitationId).eq('restaurant_id', restaurantId);
  revalidateTeam(restaurantId);
}
```

Nota: en modo soporte `getPanelContext` devuelve `readOnly: true`. Las acciones de equipo se permiten a FByte de forma explícita (`isPlatformAdmin`), porque reenviar invitaciones es tarea del superadmin. La BD lo respalda: `create_invitation` admite superadmin. En cambio, `update`/`delete` de miembros los bloquea RLS para FByte, y en ese caso la acción devuelve "No tienes permiso".

```ts
'use server';

import { revalidatePath } from 'next/cache';
import type { InviteState } from '@/lib/actions/team';
import { requirePlatformAdmin } from '@/lib/auth/guards';
import { mapDbError } from '@/lib/db-errors';
import { sendInvitationEmail } from '@/lib/email/invitation';
import { fieldErrorsFrom } from '@/lib/forms';
import { invitationUrl } from '@/lib/invitations';
import { createClient } from '@/lib/supabase/server';
import { createRestaurantSchema } from '@/lib/validation/schemas';

export type CreateRestaurantState = InviteState & { restaurantId?: string };

export async function createRestaurant(_prev: CreateRestaurantState, fd: FormData): Promise<CreateRestaurantState> {
  await requirePlatformAdmin();
  const parsed = createRestaurantSchema.safeParse({
    name: fd.get('name'),
    slug: fd.get('slug'),
    adminEmail: fd.get('adminEmail'),
  });
  if (!parsed.success) return { fieldErrors: fieldErrorsFrom(parsed.error) };

  const supabase = await createClient();
  const { data, error } = await supabase
    .rpc('create_restaurant', { p_name: parsed.data.name, p_slug: parsed.data.slug, p_admin_email: parsed.data.adminEmail })
    .single<{ restaurant_id: string; invitation_token: string }>();
  if (error || !data) return { error: mapDbError(error?.message) };

  const url = invitationUrl(data.invitation_token);
  const sent = await sendInvitationEmail({ to: parsed.data.adminEmail, restaurantName: parsed.data.name, role: 'admin', inviteUrl: url });
  revalidatePath('/admin');
  return { success: 'Restaurante creado.', restaurantId: data.restaurant_id, inviteUrl: url, email: parsed.data.adminEmail, emailSent: sent.ok };
}
```

```ts
'use server';

import { revalidatePath } from 'next/cache';
import { requirePlatformAdmin } from '@/lib/auth/guards';
import { createClient } from '@/lib/supabase/server';
import { uuidSchema } from '@/lib/validation/schemas';

const STATUSES = ['setup', 'active', 'disabled'] as const;

export async function setRestaurantStatus(fd: FormData): Promise<void> {
  await requirePlatformAdmin();
  const restaurantId = String(fd.get('restaurantId') ?? '');
  const status = String(fd.get('status') ?? '') as (typeof STATUSES)[number];
  if (!uuidSchema.safeParse(restaurantId).success || !STATUSES.includes(status)) return;
  const supabase = await createClient();
  const { error } = await supabase.rpc('set_restaurant_status', { p_restaurant_id: restaurantId, p_status: status });
  if (error) throw new Error(error.message);
  revalidatePath('/admin');
  revalidatePath(`/admin/restaurantes/${restaurantId}`);
}
```

```ts
import { fieldErrorsFrom, type FormState } from '@/lib/forms';
import { createAdminClient } from '@/lib/supabase/admin';

type Invitation = { restaurant_id: string; restaurant_name: string; email: string; role: string; has_account: boolean };

async function loadInvitation(token: string): Promise<Invitation | null> {
  const supabase = await createClient();
  const { data } = await supabase.rpc('get_invitation', { p_token: token });

export async function createAccountAndAccept(_prev: FormState, fd: FormData): Promise<FormState> {
  const token = String(fd.get('token') ?? '');
  const parsed = newAccountSchema.safeParse({ fullName: fd.get('fullName'), password: fd.get('password') });
  if (!parsed.success) return { fieldErrors: fieldErrorsFrom(parsed.error) };

  const invitation = await loadInvitation(token);
  if (!invitation) return { error: mapDbError('INVALID_INVITATION') };
  if (invitation.has_account) return { error: 'Ya tienes cuenta con este email. Entra para aceptar la invitación.' };

  // El enlace llegó al email invitado, así que damos el email por confirmado.
  const admin = createAdminClient();
  const { error: createError } = await admin.auth.admin.createUser({
    email: invitation.email,
    password: parsed.data.password,
    email_confirm: true,
    user_metadata: { full_name: parsed.data.fullName },
  });
  if (createError) {
    console.error('[invitacion] no se pudo crear la cuenta', { code: createError.code });
    return { error: mapDbError(undefined) };
  }

  const supabase = await createClient();
  const { error: signInError } = await supabase.auth.signInWithPassword({ email: invitation.email, password: parsed.data.password });
  if (signInError) return { error: mapDbError(undefined) };

  const { data: restaurantId, error } = await supabase.rpc('accept_invitation', { p_token: token });
  if (error) return { error: mapDbError(error.message) };
  redirect(`/panel/${restaurantId}`);
}

export async function acceptAsCurrentUser(_prev: FormState, fd: FormData): Promise<FormState> {
  const token = String(fd.get('token') ?? '');
  const supabase = await createClient();

  if (error) return { error: mapDbError(error.message) };

}
```

```ts
// Uso: ADMIN_PASSWORD='una-clave-larga' pnpm admin:create persona@fbytesolutions.com
import { createClient } from '@supabase/supabase-js';

const email = process.argv[2]?.trim().toLowerCase();
const password = process.env.ADMIN_PASSWORD;
const url = process.env.NEXT_PUBLIC_SUPABASE_URL;
const secret = process.env.SUPABASE_SECRET_KEY;

if (!email || !password || password.length < 12) {
  console.error("Uso: ADMIN_PASSWORD='mínimo 12 caracteres' pnpm admin:create correo@dominio.com");
  process.exit(1);
}
if (!url || !secret) {
  console.error('Faltan NEXT_PUBLIC_SUPABASE_URL o SUPABASE_SECRET_KEY en .env.local');
  process.exit(1);
}

const supabase = createClient(url, secret, { auth: { persistSession: false, autoRefreshToken: false } });

let userId: string | undefined;
const { data: created, error } = await supabase.auth.admin.createUser({
  email,
  password,
  email_confirm: true,
  user_metadata: { full_name: 'FByte Solutions' },
});
if (created?.user) {
  userId = created.user.id;
} else if (error && /already|registered|exists/i.test(error.message)) {
  for (let page = 1; !userId; page++) {
    const { data, error: listError } = await supabase.auth.admin.listUsers({ page, perPage: 200 });
    if (listError) throw listError;
    userId = data.users.find((u) => u.email?.toLowerCase() === email)?.id;
    if (data.users.length < 200) break;
  }
} else if (error) {
  throw error;
}
if (!userId) {
  console.error(`No encontré al usuario ${email}`);
  process.exit(1);
}

const { error: updateError } = await supabase.from('profiles').update({ is_platform_admin: true }).eq('user_id', userId);
if (updateError) throw updateError;
console.log(`✔ ${email} ya es superadmin de FByte`);
```

```ts
import { expect, test, type Page } from '@playwright/test';

const ADMIN_EMAIL = process.env.E2E_ADMIN_EMAIL;
const ADMIN_PASSWORD = process.env.E2E_ADMIN_PASSWORD;

async function login(page: Page, email: string, password: string) {
  await page.goto('/login');
  await page.getByLabel('Email').fill(email);
  await page.getByLabel('Contraseña').fill(password);
  await page.getByRole('button', { name: 'Entrar' }).click();
}

test('FByte da de alta un restaurante y su equipo entra al panel', async ({ page, browser }, testInfo) => {
  test.skip(!ADMIN_EMAIL || !ADMIN_PASSWORD, 'Faltan E2E_ADMIN_EMAIL y E2E_ADMIN_PASSWORD');

  const stamp = `${Date.now()}${testInfo.project.name === 'movil' ? 'm' : 'd'}`;
  const name = `E2E ${stamp}`;
  // Direcciones de prueba de Resend: se aceptan y no llegan a nadie.
  const ownerEmail = `delivered+owner${stamp}@resend.dev`;
  const staffEmail = `delivered+staff${stamp}@resend.dev`;

  // 1. FByte crea el restaurante
  await login(page, ADMIN_EMAIL!, ADMIN_PASSWORD!);
  await page.waitForURL('**/admin');
  await page.getByRole('link', { name: 'Nuevo restaurante' }).click();
  await page.getByLabel('Nombre del restaurante').fill(name);
  await page.getByLabel('Dirección pública').fill(`e2e-${stamp}`);
  await page.getByLabel('Email del administrador').fill(ownerEmail);
  await page.getByRole('button', { name: 'Crear restaurante' }).click();
  const ownerLink = await page.getByLabel('Enlace de invitación').inputValue();

  // 2. El dueño acepta y crea su acceso
  const ownerCtx = await browser.newContext();
  const owner = await ownerCtx.newPage();
  await owner.goto(new URL(ownerLink).pathname);
  await owner.getByLabel('Tu nombre').fill('Pepe Dueño');
  await owner.getByLabel('Contraseña').fill('una-clave-segura-123');
  await owner.getByRole('button', { name: 'Crear mi acceso' }).click();
  await expect(owner.getByRole('heading', { name })).toBeVisible();

  // 3. El dueño invita a alguien de sala
  await owner.getByRole('link', { name: 'Equipo' }).click();
  await owner.getByLabel('Email', { exact: true }).fill(staffEmail);
  await owner.getByLabel('Rol', { exact: true }).selectOption('staff');
  await owner.getByRole('button', { name: 'Enviar invitación' }).click();
  const staffLink = await owner.getByLabel('Enlace de invitación').inputValue();

  // 4. Sala acepta y no ve la sección Equipo
  const staffCtx = await browser.newContext();
  const staff = await staffCtx.newPage();
  await staff.goto(new URL(staffLink).pathname);
  await staff.getByLabel('Tu nombre').fill('Lucía Sala');
  await staff.getByLabel('Contraseña').fill('otra-clave-segura-456');
  await staff.getByRole('button', { name: 'Crear mi acceso' }).click();
  await expect(staff.getByRole('heading', { name })).toBeVisible();
  await expect(staff.getByRole('link', { name: 'Equipo' })).toHaveCount(0);

  // 5. FByte desactiva el restaurante y sala ve el aviso
  await page.goto('/admin');
  await page.getByRole('link', { name }).click();
  await page.getByRole('button', { name: 'Desactivar' }).click();
  await expect(page.getByRole('button', { name: 'Reactivar' })).toBeVisible();
  await staff.reload();
  await expect(staff.getByText('Este restaurante está desactivado')).toBeVisible();

  await ownerCtx.close();
  await staffCtx.close();
});
```
